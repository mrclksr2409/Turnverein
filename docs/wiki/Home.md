# Turnverein Manager – Wiki

Willkommen in der Dokumentation des **Turnverein Manager**, einem WordPress-Plugin zur Verwaltung von Sportstätten, Trainern, Gruppen und Trainingszeiten eines Turnvereins.

## Was kann das Plugin?

| Bereich | Funktionen |
|---|---|
| **Sportstätten** | Anlegen, Bearbeiten, Löschen · Adresse, Kapazität, Beschreibung · Reihenfolge per Drag & Drop · Trainingszeiten (Slots) je Sportstätte |
| **Trainer** | Kontaktdaten, Sportart, Lizenz · Profilbild aus der Mediathek · Übersicht der zugeordneten Gruppen |
| **Gruppen** | Name, Altersbereich, max. Mitglieder, Beschreibung · beliebig viele Trainer je Gruppe · Übersicht aller Trainingszeiten |
| **Belegungsplan** | Wochenplan aller Sportstätten im Admin · optional ein bestimmter Trainer je Slot |
| **Shortcodes** | Sportstätten-Tabelle, Trainer je Gruppe, Belegungsplan (gesamt, je Sportstätte, je Gruppe) – mit eigenen Überschriften |
| **Updates** | Automatische Updates direkt aus GitHub (Branch `main`) |

## Schnellstart

1. Plugin installieren und aktivieren → [[Installation und Updates]]
2. **Trainer** anlegen (optional mit Bild) → [[Trainer]]
3. **Gruppen** anlegen und Trainer zuordnen → [[Gruppen]]
4. **Sportstätten** anlegen und Trainingszeiten eintragen → [[Sportstätten]]
5. Belegungsplan prüfen → [[Belegungsplan]]
6. Shortcodes auf der Website einbauen → [[Shortcodes]]

> 💡 **Tipp:** Die Reihenfolge Trainer → Gruppen → Sportstätten spart Arbeit, weil jeder Schritt auf dem vorherigen aufbaut.
